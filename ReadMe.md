Создаётся класс Name с тремя полями типа String (surname, name, patronymic).

В конце вызывается trim(), чтобы убрать лишние пробелы от пропущенных полей.
Интерактивный ввод — через getNamePart() (только кириллица, пустое значение допустимо), попытки ввода не прекратятся, пока хотя одно бы из полей не будет пустым.

# Задание 3
## Задача 3
### Текст задачи
Города.	
Создайте	сущность	Город,	которая	будет	представлять	собой	точку	на	карте	со	следующими	
характеристиками:	
• Название	города	
• Набор	путей	к	следующим	городам,	где	путь	представляет	собой	сочетание	Города	и	
стоимости	поездки	в	него.	
Кроме	того,	Город	может	возвращать	текстовое	представление,	в	виде	названия	города	и	списка	
связанных	с	ним	городов	(в	виде	пары:	“название:стоимость”).	
Используя	разработанную	сущность	реализуйте	схему,	представленную	на	рисунке	2.	
### Алгоритм решения
Создаётся класс City с полями String name и словарём, где ключами выступают города, и их значениями - расстаяние до этого города.
Метод addOneWayRoad(City, int) добавляет дорогу в одну сторону, addTwoWayRoad(City, int) - в обе (вызывает addOneWayRoad для обоих городов).
В приведении класса к строке выводит "Город - сосед1:цена1 сосед2:цена2...", для пустой карты - фраза, что связвнных городов нет. 
Переопределены equals()/hashCode() по имени, чтобы HashSet не дублицировал города. 
Класс MapLoader читает файл карты (строки вида откуда;куда;расстояние разбиваются по ;) и строит словарь городов с односторонними дорогами. 
В основной программе есть меню с пунктами: добавить город, добавить дорогу (одностороннюю или двустороннюю), загрузить карту из файла, очистить список.

# Задание 5
## Задача 2
### Текст задачи
Кот	мяукает.	
Создайте	сущность	Кот,	которая	описывается	следующим	образом:	
• Имеет	Имя	(строка)	
• Для	создания	необходимо	указать	имя	кота.	
• Может	быть	приведен	к	текстовой	форме	вида:	“кот:	Имя”	
• Может	помяукать,	что	приводит	к	выводу	на	экран	следующего	текста:	“Имя:	мяу!”,	
вызвать	мяуканье	можно	без	параметров.	
• Может	помяукать	Nраз,	что	приводит	к	выводу	на	экран	следующего	текста:	“Имя:	мяу
мяу-…-мяу!”,	где	количество	“мяу”равно	N.	
Создайте	кота	по	имени	“Барсик”,	и	затем	пусть	он	помяукает	сначала	один	раз,	а	затем	три	раза.	
### Алгоритм решения
Создаётся класс Cat с полем String name. 
Конструктор принимает обязательно имя.
В приведении класса к строке возвращается "кот: " + name. 
Метод Meow() без параметров печатает "Имя: мяу!". 
Перегруженный Meow(int n) при n > 0 формирует строку: "Имя: ", затем n-1 раз "мяу-" и в конце "мяу!" - итого n "мяу" через дефиз.
Если n меньше или равно нулю, метод ничего не печатает, что защищает от некорректного ввода.
В основной программе реализовано меню: создать/пересоздать кота, мяукнуть один раз, мяукнуть N раз (с проверкой n >= 1).
